# דוביד · סבב H — מה יש בחבילה

רק מה שהשתנה או נוסף. מבנה התיקיות זהה לפרויקט: להעתיק מעל הקיים.

## ★★ קודם כל — הדבר הדחוף ★★

`db/18_hardening.sql` סוגר חור אבטחה שקיים **במסד שרץ עכשיו**:

> כל משתמש אנונימי יכול לשכתב את חוקי הניקוד של המשחק
> (`game.scoring_overrides`), את התקציב (`game.mode_config`),
> ולמחוק את יומן הפעילות — ישירות, בלי לעבור דרך שום פונקציית
> אדמין.

הסיבה: `db/07` הגדירה `ALTER DEFAULT PRIVILEGES ... GRANT ALL`,
ו-`db/09` שללה כתיבה רק מהטבלאות שקיימות **באותו רגע**. כל טבלה
שנוצרה במיגרציות 11–17 נולדה פתוחה.

**מה לעשות:** להריץ את `db/18_hardening.sql` ב-SQL Editor. הוא
מדפיס בסוף שורת אימות:

```
✓ הקשחה: אפס כתיבה ישירה, אפס טבלאות בלי RLS
```

אם השורה הזו לא הופיעה — משהו נכשל, והמיגרציה עוצרת בשגיאה.

## סדר ההתקנה

1. **מסד** — SQL Editor, לפי הסדר:
   `db/16` → `db/17` → **`db/18`**
   (או פשוט להדביק את `db/RUN-ALL.sql` כולו — הוא כולל הכל.)
2. **קוד** — להעתיק `src/`, `tests/`, `scripts/`, `supabase/`.
3. **Edge Functions** — לפרוס מחדש את `access-code`
   (`supabase functions deploy access-code`). התיקון שם הוא
   הגנת brute-force שלא הייתה קיימת.
4. ⚠ **להגדיר `APP_ORIGIN`** בסודות ה-Edge Functions:
   `https://dubid.dubelteam.com`. ברירת המחדל תוקנה, אבל עדיף
   מפורש.
5. `npm test` · `npx tsc --noEmit`.

## מה חדש בשימוש

### פרסום פנימי
לוח הניהול → לשונית **פרסום**. ארבע מודעות מגיעות מוזרעות
(שתיים לכל מותג). לכל מודעה: מותג, כותרת, גוף, קריאה לפעולה,
משקל 1–10, מסכים, וחלון תאריכים. יש תצוגה מקדימה חיה ומספרי
חשיפות/קליקים.

הרצועה מופיעה בלובי, בדירוג, בהרכב הנעול, בכרטיס ובזירה;
במסך החוקים מופיעה שורה אחת בלבד.

★ טבלה ריקה = ברירות המחדל שבקוד. אין מצב שהמסך ריק.

### בוטים
לוח הניהול → לשונית **בוטים** (קודם היו קבורים בתחתית "פעילות").
בוחרים מצב, כמות, ולוחצים. הם מגישים כמו משתתפים רגילים
ומסומנים בתג «בוט» בכל מקום.

### שיתוף ההרכב
במסך ההרכב הנעול יש עכשיו כפתור שיתוף קבוע — סטורי, וואטסאפ,
העתקת קישור, ושמירת תמונה. הכרטיס הוא בדיוק זה שקפץ אחרי
ההגשה, ואפשר לפתוח אותו כמה פעמים שרוצים.

### סביבת בדיקות
`cp .env.staging.example .env.local` אחרי הקמת פרויקט Supabase
שני. הפס בראש לוח הניהול יראה «בדיקות» במקום «⚠ ייצור — דאטה
חיה». בלי זה, `npm run dev` כותב לדאטה של המשתמשים.

## מה נבדק

336 בדיקות יחידה · 9 חבילות SQL על PostgreSQL 16 נקי, בשתי
ריצות רצופות · `tsc --noEmit` נקי · שני smoke של רינדור שרת ·
צילומי מסך של ההרכב הנעול ושל ארבע המודעות.

בדיקת ההקשחה (`db/tests/09_hardening.sql`) לא בודקת קטלוגים —
היא עושה `SET ROLE anon` ומריצה את ההתקפה עצמה.

**לא ניתן לבדוק כאן:** `npm run build`, Edge Functions בפועל,
Google OAuth, Offsides, Realtime.
