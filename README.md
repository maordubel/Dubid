## ⚠️ קודם כול: הסגלים שסיפקת חסרים

אבל יש כאן בעיה אריתמטית שאי אפשר לעקוף בקוד:

> עם הכלל "שחקן אחד מכל קבוצה", **11 שחקנים דורשים 11 קבוצות שונות.**
> בקובץ יש 6. חסרות 5 לפחות (ובליגה האמיתית 14 — כלומר חסרות 8).

**מה עשיתי:** לא שברתי את הכלל ולא המצאתי שחקנים. במקום זה
`resolveRules()` מזהה שיש 6 קבוצות ומריץ **מצב הדגמה** עם הרכב של 6
(מערך `2-2-1`), עם באנר קבוע שמסביר בדיוק מה חסר. הרגע שיעלו 11+
קבוצות — ההרכב חוזר ל-11 אוטומטית, בלי שינוי קוד.

**מה חסר מהקובץ** (`scripts/squads.report.md` — נוצר אוטומטית):

## 1 · מנוע הניקוד — לפי המפרט שהגדרת

```ts
import { scoreLineup } from './lib/scoring/engine.ts';
import { IL_PREMIER } from './lib/scoring/rules.ts';

const score = scoreLineup(lineup, performances, outcomes, IL_PREMIER);
```

**רובד 1 — ציון אינדיבידואלי**

| פעולה | נקודות |
|---|---|
| שער — שוער / מגן | 6 |
| שער — קשר | 5 |
| שער — חלוץ | 4 |
| בישול | 3 |
| שער נקי (דורש 60 דקות) | 4 |
| כרטיס צהוב | ‎-1 |
| כרטיס אדום | ‎-3 |

**רובד 2 — בונוס קבוצתי אמיתי:** ניצחון `+4` · תיקו `+1` · הפסד `0`.
פר שחקן, לפי הקבוצה שהוא מייצג בהרכב.

**רובד 3 — שער ההרכב הווירטואלי:** סכימת שערי כל הקבוצות שבהרכב
לקופה אחת; כל 2 שערים = שער וירטואלי של `+5`. שאריות נשמרות ומופיעות
בפירוט (`meta.remainder`).

**רובד 4 — הקפטן הדובידי:** `×3`, חסינות לצהוב (60 דקות ומעלה + לא
הפסידו; אדום לא נסלח), והעברה אוטומטית לסגן אם הקפטן לא שיחק.
ציון שלילי לא מוכפל.

> **שתי החלטות שנגזרו מהמפרט וכדאי שתראה אותן:**
> 1. **אין נקודות על הופעה.** מגן ששיחק 90 דקות בלי שער ובלי קלין-שיט
>    מקבל **0**. זה נאמן למפרט, אבל מגדיל את מרכיב המזל. הפעלה:
>    `minutesPlayed: 1, minutes60Plus: 2` ב-`rules.ts` — שורה אחת.
> 2. **קלין-שיט אחיד 4 לכל העמדות** — כולל חלוצים. אם התכוונת רק
>    לשוער ומגן: `cleanSheet: { GK: 4, DEF: 4, MID: 0, FWD: 0 }`.

## 2 · אכיפת "שחקן אחד מכל קבוצה" — ארבע שכבות

| שכבה | מנגנון |
|---|---|
| **UI — מניעה** | רצועת "כיסוי קבוצות" מעל המגרש: 6 צ׳יפים, מלאים בכתום, ריקים באפור |
| **UI — הסבר** | בגיליון הבחירה שחקן מקבוצה תפוסה **מואפר + קו חוצה + ✕**, והכיתוב אומר בדיוק *מי* חוסם: „מכבי חיפה · כבר בחרת את כיוף“. הוא לא נעלם — כדי שתדע את מי להחליף |
| **שירות** | `validateLineup()` — קודי שגיאה מתורגמים he/en, נבדק לפני כל כתיבה ובתחילת כל חישוב ניקוד |
| **DB** | `UNIQUE (lineup_id, team_id)` + טריגר הגשה + `one_captain_per_lineup` |

`teamBlock()` מחזיר גם את `occupiedBy` — זה מה שמאפשר ל-UI לומר "כבר
בחרת את X" במקום להאפיר בלי הסבר.

## 3 · כרטיס השיתוף

`preview/share-card.png` — **רינדור אמיתי מהקוד, עם השחקנים שסיפקת.**

1080×1920 (סטורי / טיקטוק / סטטוס וואטסאפ), מצויר על Canvas ללא שום
תלות חיצונית — כולל מחולל QR שנכתב מאפס. כולל את הלוגו, הציון, פירוק
לארבעת הרכיבים, ההרכב עם הקפטן מסומן, ו-`DUBID.DUBELTEAM.COM`.

שיתוף בלחיצה אחת (`share.ts`): `navigator.share` עם קובץ → נפילה
לשיתוף טקסט → נפילה להורדה + העתקת קישור. יש גם כפתור וואטסאפ ייעודי.
הקנבס וה-Blob מרונדרים מראש ב-`useEffect`, כי ספארי חוסם שיתוף אם יש
`await` ארוך בין הלחיצה לקריאה.

## 4 · מובייל ו-RTL

**הניווט התחתון לא מסתיר תוכן** — שלושה תיקונים, לא אחד:
גובה הניווט חשוף כמשתנה CSS (`--nav-h`) ש-`AppShell` מוסיף כ-padding
לאזור התוכן; `env(safe-area-inset-bottom)` בתוך הגובה; ו-`100dvh`
במקום `100vh`. `index.html` כולל `viewport-fit=cover` — בלעדיו
ה-`env()` מחזיר 0 וכל התיקון לא שווה כלום.

מעל `lg` אותם פריטים הופכים ל-`SideRail` אנכי + עמודת צד.
אותן קומפוננטות, לא שני מימושים.

**RTL:** אין `left`/`right`/`ml-`/`mr-` בשום קובץ — רק
`ps/pe/ms/me/start/end/border-s/border-e/text-start`. מספרים ב-`.num`
(`dir="ltr"` + `tabular-nums` + `unicode-bidi: isolate`), שמות לטיניים
בתוך עברית ב-`<bdi>`.

## 5 · מה אומת בפועל

```
npm test                                          →  69 tests, 69 pass
psql -f db/01_schema.sql, 02_..., 03_seed_squads   →  נקי, ואידמפוטנטי
```

* **מנוע הניקוד — 31 טסטים.** כל ערך במפרט נבדק בנפרד, ובנוסף תרחיש
  מחזור מלא שחושב ביד: אישי 32 · תוצאה 23 · קפטן 25 · וירטואלי 35 = **115**.
* **מחולל ה-QR — 20 טסטים** בקריאה הפוכה: מסיר מסכה, קורא זיגזג, מפרק
  שזירה, מאמת Reed–Solomon, ומשחזר את המחרוזת. ארבע רמות ECC + עברית.
* **קבצי הפריסה — 9 טסטים.** נולדו מבאג אמיתי: מפתח `"//"` בתור הערה
  בתוך `vercel.json` הפיל את כל הפריסה. הטסטים מוודאים שאין מפתחות
  זרים, שיש fallback ל-SPA, ושכל אייקון ב-manifest קיים.
* **הדאטה — 9 טסטים.** כל שחקן משויך לקבוצה קיימת, אין מזהים כפולים,
  והטסט `★ אזהרה: אין מספיק קבוצות` מתעד את המחסור במפורש — **הוא
  ייכשל בכוונה** ברגע שיעלו כל הקבוצות, כתזכורת לעדכן את הציפייה.
* **DB:** הסיד הורץ פעמיים ברצף — 6 קבוצות / 47 שחקנים בשתי הפעמים,
  אפס כפילויות. האזהרה על מחסור הקבוצות נורית מתוך ה-SQL עצמו.

### מה לא אומת

* `npm run build` **לא רץ כאן** — אין גישה ל-npm registry בסביבה הזו.
  הסריקה שעשיתי (ייבואים לא בשימוש, `import type`, מחלקות Tailwind לא
  חוקיות) נקייה. `build` הוא כעת `vite build` בלבד — בדיקת הטיפוסים
  עברה ל-CI, כדי ששגיאת טיפוס אחת לא תפיל פריסה לפרודקשן.
* `navigator.share` עם קבצים — צריך מכשיר אמיתי (iOS Safari / Chrome אנדרואיד).
* ה-Edge Function לא הורץ מול פרויקט Supabase חי.
