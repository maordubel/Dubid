## מה שאמור לקרות

| | |
|---|---|
| כל אחד נכנס | רואה "אורח", בלי טופס |
| בונה הרכב ומגיש | "שולח לשרת…" ואז ההרכב נעול |
| מרענן | ההרכב עדיין שם |
| מסתכל בדירוג לפני הדדליין | **רואה רק את עצמו** — וזה נכון |
| אחרי הדדליין | **כולם רואים את כולם** |
| פותח זירה ומשתף קוד | כולם באותה זירה, טבלה משותפת |

★ **למה הדירוג ריק לפני הדדליין:** הרכב גלוי לפני הנעילה הוא
העתקה. אחרי הנעילה הכל נפתח אוטומטית, בלי שתעשה כלום.

# אחרי המשחקים — התוצאות

**אין API כדורגל, ולא צריך.** הכל ידני, וזה תוכנן ככה.

▸ `/admin` → לשונית **"תוצאות"**

1. תוצאה לכל משחק → "שמירה"
2. "הזנת שחקנים" → דקות, שערים, בישולים, כרטיסים
3. **"פרסם דירוג"**

★ ברגע שלוחצים "פרסם", הדירוג נפתח אצל כולם **בלי שירעננו** —
`realtime` דוחף את זה למסך.

⚠ טעית בתוצאה? מותר לבטל פרסום, לתקן, ולפרסם שוב. הכל נרשם
ב-`game.audit_logs`.

# רוצה לבדוק לפני שאתה מזמין חברים?

הזז את הדדליין לעבר, ותראה את הדירוג נפתח:

```sql
UPDATE game.gameweeks SET lock_at = now() - interval '1 minute' WHERE code='gw-2';
```

ולהחזיר:

```sql
UPDATE game.gameweeks SET lock_at = TIMESTAMPTZ '2026-08-29 20:00:00+03' WHERE code='gw-2';
```

# מה לא יעבוד, ואתה כבר יודע

**API כדורגל.** אין מנוי, ולא נדרש — התוצאות ידניות דרך האדמין.
שום דבר אחר לא תלוי בו.

**קישור חשבון אופסיידס.** דורש Email OTP בפרויקט של אופסיידס
(`docs/OFFSIDES-SYNC.md`). לא חוסם שום דבר במשחק.

**קוד חד־פעמי בין מכשירים.** דורש פריסת שתי Edge Functions
(`docs/INSTALL.md` שלב 4). גם הוא לא חוסם — אורח משחק בלעדיו.
